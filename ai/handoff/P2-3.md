## Owner setup required (in order)
1. Google Cloud Console: create OAuth client (Web). Authorized redirect URI = the "Callback URL (for OAuth)" shown in Supabase > Authentication > Sign In / Providers > Google.
2. Supabase: enable Google provider, paste Client ID and Secret. Disable other providers (email) you do not want.
3. Supabase > Authentication > URL Configuration: Site URL = production URL; add Redirect URLs `http://localhost:3000/auth/callback` and the production `/auth/callback`.
4. `.env`: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (Project Settings > API), plus `DATABASE_URL`, `DIRECT_URL`.
5. Make sure the `accounts` table exists (schema is still UNMIGRATED; see DATA_MODEL.md). Without it login fails with `?error=account`.
6. Test: sign in -> `/dashboard` shows your email; row appears in `accounts`; Keluar; open `/pendaftaran` signed out -> redirected.
